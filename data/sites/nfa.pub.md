佐证：卖的是 NFA（No Full Access）账号：只给 Steam 登录令牌、不给密码和邮箱，所以能压到每个 €0.30–2，买家多用来开小号、躲封禁；当前域名 2026 年注册，更早的旧站属于前任持有人；运营者昵称 archie，Discord 邀请码 archievable 和 GitHub 名 fakearchie 一致；客服走 Discord 工单，Telegram 频道只有 81 个订阅；给转卖商开了库存 API，GitHub 上有配套的 Windows 加载器 nfatool，用令牌一键登录 Steam、买号换号，还在持续更新；Gridinsoft 给的信任分是 73/100。
推论：10.78 万次总访问是估算的：Similarweb 公开页没给这个站的访问量，按全球排名 #313824 套用 437 个有真实访问的站拟合出来的曲线，一半的站误差在 17% 以内，所以渠道圆都标了 ≈。两个渠道圆按 88.79% 和 11.21% 切开，各路怎么拆是推论：直接输网址 9.57 = 老买家补货 6.2 + Discord 群 2.2 + 玩家朋友推荐 0.8 + YouTube 视频 0.37；其余渠道 1.21 = YouTube 视频 0.46 + 玩家朋友推荐后搜名字 0.3 + Discord 链接 0.25 + 老买家搜品牌名 0.2。Discord 桌面端点链接多半记成直接访问，所以 Discord 这一路大部分放在直接里；“从已有 Discord 圈子迁过来”是档案的推测，没找到首发帖。在 Discord 群里看到链接 20% 进站、被朋友推荐 40% 进站、刷到 YouTube 视频 3% 进站，这几个比例是猜的。
