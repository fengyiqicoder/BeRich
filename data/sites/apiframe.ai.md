## 上个月流量模型
主引擎是搜索占位（SEO）：直接访问占 70%（多是登录控制台的老开发者），搜索里 94% 是自然搜索，热门词是 midjourney api、suno api、wan3.0 这类“模型 + API”。
涡轮加速是每接一个热门新模型（Wan、Seedance 等）就多一批搜索词；上个月访问比上两个月多 8%。
按推算，约六成的访问是老开发者登录回访；每 100 次访问约 3 笔付款（含续费）。
模型：Lenny 的赛车增长框架。引擎 = 搜索占位（“某模型 + API”的开发者搜索词，多语种页面）；涡轮加速 = 每接入一个热门新模型就多一批搜索词；润滑剂 = 按积分用量计费，开发者反复登录和充值。
真实数据：6.5 万次访问、直接占 69.71%、渠道排名（直接、自然搜索、引荐）、搜索里自然搜索 94.22%、搜索词、国家、跳出率 40.52%、每次 1.97 页、停留 32 秒、环比 +8.33%、引荐网站份额来自 Similarweb 公开页上个月；1,952 笔付款、收入 47,039 美元、现有 936 个订阅来自 TrustMRR（付款那个月就是上个月）。第二、第三渠道各占多少公开页没给。
佐证：Similarweb 的非品牌搜索词有 suno api、midjourney api、wan3.0；官网有韩语、日语的 Midjourney API 页面和博客；官网新闻位写 Seedance 2.5 已上线；官网 Affiliates 页写返佣，另有 Discord 社区；官网自称服务 9,800 多位开发者和公司。
推论：把两个渠道圆拆给四路：直接输网址 4.5312 = 开发者登录 3.6 + 搜到后再直接来 0.4 + 新模型公告 0.1 + 返佣和别的网站 0.4312；搜索和引荐 1.9688 = 搜索结果 1.2 + 新模型公告 0.25 + 返佣和别的网站 0.3188 + 登录前搜品牌词 0.2。回访按直接访问占七成推，约占六成。看到搜索结果 10% 进站、新模型公告 5%、返佣 20%，这几个比例和拆法都是猜的。付款多是老开发者的积分续费，每 100 次访问约 3 笔付款（含续费）只能当参考。

## 一、产品
- 产品：把 Midjourney、Suno、Wan 等图像/视频/音乐生成模型统一成一个 REST API，开发者和无代码用户不用分别对接各家供应商就能给自己的应用加上媒体生成功能。
- 用户群体：要在自家应用里接入 AI 生图/视频/音乐的开发者和小公司，以及用 Zapier、Make 等无代码工具批量生成素材的营销和电商团队
- 定位：最早一批做 Midjourney 非官方 API 的聚合商，后来扩成多模型统一接口，按用量计费、只对成功生成收费
- 定价：按积分用量计费，各模型单价不同；免费起步，付费套餐 $39/月（首月 $19） 收费方式: 混合 免费版: 有 来源: 首页
- 官网价目：$39/mo (first month $19)
- 官网可见的获客入口：联盟/推荐计划、Discord 社群
- 英文简介：Developer API giving one key to 70+ AI image, video and music generation models
