## 上个月流量模型
主引擎是推荐返佣：邀请双方各得首充 8% 额度，推广伙伴拿现金返佣；直接打开占 67%，引荐排第二，搜索很少。

模型：Lenny 的赛车增长框架。引擎 = 推荐返佣（邀请双方各得首充 8% 额度、推广伙伴现金返佣、项目赞助挂链接）；涡轮加速 = V2EX 推广区的赠金帖，打进中文薅羊毛开发者圈；润滑剂 = 低倍率分组和充值门槛，老用户为了便宜价格回来充值。

## 一、产品
- 产品：低价大模型 API 中转，一个接口调用 GPT、Claude、Grok、Gemini 及图像/视频模型，按请求记录用量和成本。
- 用户群体：需要低价调用海外大模型的开发者，以中国用户为最多
- 定位：比官方更便宜的 API 中转，带分组容灾、插件和联盟分佣
- 定价：按量计费，约 200 个模型按百万 token/秒/次/张计价；Claude 专属价需单次充值 US$50，OpenAI 需 US$20 收费方式: 按量 免费版: 无 来源: 已有
- 官网价目：usage-based USD per 1M tokens / per second / per request / per image, ~200 models (e.g. claude-opus-5-5 claude-premium USD 2, gpt-5.5 openai-stable USD 0.4, deepseek-v4-pro deepseek-stable USD 0.77); Claude 专属价需单次充值 US$50；OpenAI US$20 (点数)
- 官网可见的获客入口：联盟/推荐计划
- 传播机制：公开主页/排行 Project Plaza: 'Explore projects supported by or partnering with Modelflare.'; affiliate: 'Introduce your audience to Modelflare'
- 英文简介：Lower-cost AI API gateway giving access to GPT, Claude, Grok and image/video models with per-request cost tracking
- 价格来源：modelflare.dev（https://modelflare.dev/pricing）
