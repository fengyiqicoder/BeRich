## 上个月流量模型
主引擎是开源仓库带品牌：GitHub 上一批“付费 AI 产品的开源替代”仓库后端都默认调 muapi，开发者要跑起来就得来拿 API key。
润滑剂是按次充值和推荐返额：开发者接入后反复回来充值，推荐人拿被推荐人首充的 10%，白标让下游开发者变成分销商。
按推算，四成多访问是开发者回来充值、看文档；每 100 次访问约 11 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 开源仓库带品牌（开源替代仓库后端绑定 muapi，开发者 clone 下来就得来拿 key）；润滑剂 = 按次充值的复购、首充返 10% 的推荐计划和白标分销。
真实数据：36.3 万次访问、环比 +14.05%、第一大渠道直接占 50.84%、前三渠道排名（直接、自然搜索、引荐）、搜索里自然搜索占 100%、搜索词 477 个、热门搜索词（muapi、muapi ai、open generative ai、grok 4.7、muapi api key）、引荐前几名（msn.com 0.36%、vadoo.tv 0.34%、stripe.com 0.3%）、引荐类目（编程和开发者软件 85.82%）、社交来源（YouTube、Instagram、Facebook）、国家（印度 23.33%、美国 14.19%、巴西 4.97%、巴基斯坦 4.3%、韩国 3.03%）、跳出率 35.03%、每次 4.83 页、平均停留 2 分 50 秒，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。38682 次（3.87 万）去 Stripe 付费页来自 quietmoney 收款页数据。
佐证：背后是班加罗尔小公司 Vadoo，创始人 Anil Matcha 的 GitHub 有 2500 多粉丝；2023 年起在个人号和 SamurAIGPT 组织大量建仓库，Open-Generative-AI 约 3.08 万星，被 Trendshift 和 Telegram 的 GitHub 推荐频道转发；GitHub 搜 muapi 有 220 个仓库，不少以新模型命名的仓库是旧仓库改名重用；推荐计划返首充 10%，白标 $49/月起。
推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 18.45 = 老开发者 13 + GitHub 仓库 3 + 推荐和白标 2.45；其余渠道 17.85 = GitHub 仓库带来的引荐和搜仓库名 6.5 + 搜新模型 API 4 + 推荐和白标 3.85 + 老开发者搜名字 3.5。拆的时候参考了档案里的旧渠道数（搜索约 37%、引荐约 7%、品牌词 73%），只当参考。刷到仓库、搜到新模型 5% 进站，被推荐 30% 进站，这几个比例是猜的。
