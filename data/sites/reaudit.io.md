## 上个月流量模型
主引擎是搜索占位：搜索词几乎全是非品牌词，一族是 is your site agent ready，对应官网无需注册的免费检查。
没有查到涡轮加速；“Who AI recommends”行业榜单、插件和 MCP 服务器是内容和工具，带来多少访问没有数据。
按推算，访问量是估算的（按付款笔数）；每 100 次访问约 0.3 笔付款（含续费），这个比例是估算时用的中位数，收入大头是高价代运营单。
模型：Lenny 的赛车增长框架。引擎 = 搜索占位（免费 agent-readiness 检查和行业榜单做非品牌搜索，创始人未自填渠道，档案标的增长引擎是搜索占位）；润滑剂 = 订阅客户登录回访；涡轮加速 = 没有查到。
真实数据：直接占 35.75%（第一大渠道）、渠道排名（直接、自然搜索、引荐）、搜索里自然搜索 100%、搜索词、国家（希腊 72.59%、印度 27.41%）、跳出率 36.74%、环比 -62.24% 来自 Similarweb 公开页上个月；5 笔付款、收入 2,603 美元、月末 MRR 1,017 美元、5 个订阅来自 TrustMRR。0.15 万次总访问不是真数，是按付款笔数估算的（付款笔数 ÷ 访问的中位比例 0.0034，用 230 个有真实访问的站算）。
佐证：搜索词与官网的免费检查直接对应；官网发布“Who AI recommends”行业榜单，创始人在 GitHub 发布了 Cursor 和 Claude Code 插件，官网称有 MCP 服务器；档案提到国家构成里的希腊和印度可能多是自测或爬虫流量。
推论：总访问是从付款笔数倒推的，而付款里有高价代运营单，所以误差可能有几倍，每 100 次访问约 0.3 笔付款只是估算时用的中位比例。把两个渠道圆拆给四路：直接输网址 0.0536 = 订阅客户回访 0.005 + 收到联系或听说后输网址 0.0486；搜索和链接 0.0964 = 搜免费检查 0.07 + 榜单和插件 0.0264。听说后 30%、搜索 3%、榜单 5% 进站，这几个比例和拆法都是猜的。
