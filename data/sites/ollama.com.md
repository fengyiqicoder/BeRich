## 上个月流量模型
主引擎是病毒传播：直接输网址占 43%，搜索里八成多搜的是 ollama 这个名字，教程作者和第三方工具默认就用它。
每个新开源模型发布都是一次涡轮加速：Llama 2、DeepSeek R1、gpt-oss 一出，Ollama 当天上架，教程和视频跟着刷一波。
按推算，近一半的访问是老用户回来找模型、下新版；每 100 次访问约 0.8 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 病毒传播（开源工具好用 → 教程作者和第三方工具默认用它 → 新用户进站）；涡轮加速 = 每次新开源模型发布；润滑剂 = Cloud 订阅和 coding agent 接入，把本地用户留在 Ollama 里。
真实数据：903.2 万次访问、环比 -11.65%、各渠道占比（直接 42.82%；自然搜索 42.69% + AI 4.06% + 付费搜索 0.01% 合成搜索；引荐 5.34% + 自然社交 3.87% + 邮件 1.13% + 展示广告 0.08% 合成链接）、国家（中国 16.71%、美国 12.49%、印度 9.44%、德国 3.84%、巴西 3.17%）、电脑 85.08%、跳出率 37.07%、平均停留 4 分 18 秒、每次 4.78 页、引荐前几名（github.com 26.12%、huggingface.co 16.67%、checkout.stripe.com 10.10%、quark.cn 6.44%）、社交来源 YouTube 56.93%、Facebook 13.82%、Reddit 10.60%、X 9.41%、外链去向 stripe.com 32.78%、github.com 27.86%，来自 Similarweb 上个月；搜索热词（ollama、ollama models、olama、ollama download、ollama cloud）来自之前存的 Similarweb 记录；73066 次（7.31 万）去 Stripe 付费页来自 quietmoney 收款页数据，invoice.stripe.com 为 0。档案里的旧渠道数（搜索 42.9%、中国 19.64%、品牌词 85.7%）是之前的口径，这里只拿品牌词比例做参考。
佐证：v0.0.1 2023 年在 GitHub 发布，十天后赶上 Llama 2 开源，Simon Willison 当天写博文推荐，Replicate 几天后收录进本地运行教程；官方博客几乎每次大模型发布都有当天上架文；HN 上讨论过 ollama.org 仿冒站，说明品牌搜索量已经很大；2026 年 B 轮 $6500 万，公司自报 890 万开发者、6.7 万+ 集成；2026 年接入 Claude Code、Codex、OpenClaw。
推论：每一路带来多少次进站，是把渠道访问拆给各路算的（直接输网址 386.8 = 老用户 250 + 第三方工具 60 + 教程 40 + 博客新闻 36.8；搜索 422.3 = 老用户 180 + 教程 140 + 第三方工具 70 + 博客新闻 32.3；链接 94.1 = 教程 40 + 第三方工具 21 + 博客新闻 18.1 + 老用户 15）。刷到教程 5% 进站、被第三方工具要求安装 50% 进站、看到博客新闻 10% 进站，这几个比例是猜的。中国流量多来自“本地部署 DeepSeek”一类中文教程，也是推论。
