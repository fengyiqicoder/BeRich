按推算，每 100 次访问约 0.8 笔付款（含续费）；访问量是估算的（按全球排名），而且客户都是企业订阅，所以这个比例只是个量级。
模型：Lenny 的赛车增长框架。引擎 = 销售（预约演示成交，新客推测来自设备融资行业的人脉、合作伙伴和行业媒体）；润滑剂 = 企业客户的订阅续费；涡轮加速 = 没查到。
真实数据：直接访问占 38.93%、渠道排名（直接、自然搜索、引荐）、搜索词只有 3 个、跳出率 34.53%、每次 1.21 页来自 Similarweb 公开页；0.29 万次（约 2,854 次）总访问不是真数，是按 Similarweb 全球排名 #5937913 估算的（用 215 个有真实访问的站拟合，一半的站误差在 15% 以内）；22 笔付款（Stripe）、收入 27,055 美元、18 个订阅来自 TrustMRR。
佐证：EF News 报道设备融资咨询公司 Consult Disrupt 与 LeadX 合作；Equipment Finance News 报道客户 KLC Financial 使用扩展后的 UCC 备案追踪功能；官网用设备融资和放贷公司的 Logo 做背书，成交靠预约演示，官网没有推荐、分享机制；Similarweb 公开页写国家是印度 100%，档案认为流量太小，样本不可信。
推论：把两个渠道圆拆给四路：直接输网址 0.1129 = 同行介绍 0.0679 + 客户登录 0.045；搜 leadx、点链接等 0.1771 = 同行介绍后搜品牌 0.03 + 合作和报道 0.05 + 搜索 0.07 + 客户登录 0.0271。同行介绍 40%、合作和报道 10%、搜索 5% 进站，这几个比例和拆法都是猜的。访问量本身是估算的，很可能偏差较大；企业订阅的月末 MRR 除以 18 个订阅约 1,200 美元，所以每 100 次访问约 0.8 笔付款只是个量级。

## 一、产品
- 产品：把企业信息、决策人联系方式、5000 万条以上 UCC 留置备案和设备所有权信号整合成一个平台，带 CRM 集成和 API，让销售和风控团队先找到并判断目标企业再外联。
- 用户群体：做设备融资、商业贷款、小企业放贷的金融公司销售与风控团队，以及需要企业数据 API 的内部数据团队
- 定位：专攻美国设备融资和商业贷款行业，独家整合 UCC 备案、设备留置和联系人数据，不卖通用 B2B 名单
- 定价：官网不公开价格，需预约演示联系销售；API 为按积分计费的数据补全；TrustMRR 记 18 个订阅
- 官网可见的获客入口：媒体报道
- 英文简介：B2B data platform combining company, contact, UCC filing and equipment ownership records via web platform, CRM integrations and API
> “"Embed LeadX data into internal tools" is data integration, not a brand badge. Pricing via demo/sales; API mentions "credit-based enrichment". Nav has "Customers & Press"; founded 2022.”（官网原文）
