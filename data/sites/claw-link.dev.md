## 上个月流量模型
主引擎是搜索占位加依附上游生态：用户在 OpenClaw、Hermes Agent 里装插件，授权要到官网完成，搜索词是 Agent 使用场景里的具体问题。
没有查到一次性的爆发事件；订阅用户每接一个新应用就会回来授权，是润滑剂。
按推算，上个月约 1.6 万次访问、234 笔付款（含续费）；每 100 次访问约 1.5 笔付款（含续费）。访问量是估算的。
模型：Lenny 的赛车增长框架。引擎 = 搜索占位加依附上游生态（OpenClaw、Hermes Agent 用户装插件、授权，搜具体问题）；涡轮加速 = 没有查到明确事件；润滑剂 = 订阅用户接新应用时的回访。
真实数据：直接访问占 40.46%、前三大渠道排名（直接、自然搜索、引荐）、99 个搜索词、国家、跳出率 39.72% 来自 Similarweb 公开页；上个月 234 笔 Polar 成功收款来自 TrustMRR（真数，含续费）；上个月 96 次付费页访问来自 quietmoney 收款页数据。上个月总访问约 1.59 万是按 Similarweb 全球排名估算的（用 260 个有真实访问的站拟合，一半的站误差在 16% 以内）。
佐证：npm 上有 @useclawlink/openclaw-plugin，描述为一个 skill 管 39,000 多个工具；官网挂 Discord、X、LinkedIn；TrustMRR 记录有 240 个订阅，月付 6 美元起；创始人没有自填渠道，也没有找到首发帖。
推论：直接访问 0.6439 万 = 装插件后去官网授权 0.3 + 老用户 0.25 + 刷到 Discord、X 的内容 0.0939；其余 0.9475 万 = 搜具体问题 0.5414 + 装插件 0.2 + 老用户 0.15 + Discord、X 0.0561。装插件 10%、搜索 5%、社区 3% 的进站比例，以及老用户占四分之一，都是猜的。每 100 次访问约 1.5 笔付款比同类站高，可能是估算的访问偏低，也可能是订阅续费占了大头。
