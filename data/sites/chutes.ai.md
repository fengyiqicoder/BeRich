## 上个月流量模型
主引擎是口碑传播：免费、便宜的 DeepSeek 在 SillyTavern、Cursor 论坛、HN 的省钱圈里口口相传，直接打开占 70%，搜索全是品牌词。
涡轮加速是 DeepSeek 热潮：2025 年初上线正赶上 DeepSeek R1，半年里 token 量涨了 250 倍；2026 年起又投 Reddit 广告往加密圈外拓客。
按推算，过半访问是回来查额度、拿 API key 的老用户；每 100 次访问约 5.8 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 口碑传播（免费、便宜的开源模型额度在角色扮演圈、编程 Agent 省钱圈里传开，再加上 OpenRouter 和 Bittensor 生态的上游分发）；涡轮加速 = 赶上 DeepSeek R1 热潮；之后加了 Reddit 广告买量；润滑剂 = API 持续调用，老用户天天回来查额度。
真实数据：29.51 万次访问、环比 -21.36%、第一大渠道直接占 70.31%、前三渠道排名（直接、自然搜索、引荐）、搜索里自然搜索占 100%、热门搜索词（chutes、chutes ai、chutesai、chutes api key、chutes status）、引荐前几名（taostats.io 3.73%、freellm.net 3.28%、vk.ru 1.88%）、社交来源（Reddit、YouTube、X）、国家（美国 55.27%、沙特 7.49%、荷兰 7.13%、俄罗斯 4.24%、印尼 3.82%）、跳出率 38.95%、每次 5.28 页、平均停留 2 分 25 秒，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。17192 次（1.72 万）去 Stripe 付费页来自 quietmoney 收款页数据，pay.stripe.com 和 invoice.stripe.com 为 0；上两个月 26823 次，上三个月 8185 次，再往前三个月月均 15733 次。档案里的“直接 78.5%、搜索 17.9%”是 Semrush 电脑端口径，这里只拿来判断第二个圆里搜索最多，不当全站占比。
佐证：2025 年初公开上线，和 DeepSeek R1 发布同期；2025 年上半年 token 量涨了 250 倍，日均约 1000 亿；Cursor 论坛有人说“Chutes.ai 免费提供 DeepSeek”；免费期结束后改成一次性 $5 解锁每日额度，再到 $10、$20 的订阅；官方 X 说砍掉一半低价值 token 后每 token 收入涨 37.7%，之后开始投 Reddit 广告。
推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 20.75 = 老用户 14.0 + 社区推荐 3.5 + 上游平台 2.0 + Reddit 广告后直接打开 1.25；其余渠道 8.76 = 社区推荐后搜名字 3.0 + taostats.io 等引荐 2.96 + 老用户搜 chutes api key、chutes status 1.8 + 点 Reddit 广告 1.0。看到社区推荐和在上游平台接触到 10% 点过来、刷到广告 1% 点进来，这几个比例是猜的。
