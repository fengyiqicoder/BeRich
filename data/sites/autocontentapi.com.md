## 上个月流量模型
主引擎是SEO（依附 NotebookLM 的搜索词）：直接访问占 40%，非品牌搜索词里有 notebooklm api、notbook mcp for codex。
涡轮加速是依附上游热度：谷歌 NotebookLM 的 AI 播客走红、官方又没有 API（档案的推测）；上个月访问环比 +55%。
按推算，约 18% 的访问是订阅用户回访；每 100 次访问约 0.79 笔付款（含续费，付款笔数是近似值）。
模型：Lenny 的赛车增长框架。引擎 = SEO（博客和搜索词占住 NotebookLM 的 API 需求）；涡轮加速 = 依附谷歌 NotebookLM 的热度（档案的推测）；润滑剂 = 订阅积分续费。
真实数据：1.8 万次访问、直接占 40.18%、环比 +54.78%、渠道排名（直接、自然搜索、引荐）、搜索里自然搜索 100%、49 个搜索词、社交只有 Reddit、国家、跳出率 37.89%、每次 1.57 页、停留 6 秒来自 Similarweb 公开页上个月；145 个订阅来自 TrustMRR；142 笔付款、收入约 16,908 美元也来自 TrustMRR，但 TrustMRR 的收入同步已中断，用的是最后有收入那个月的数，不是上个月的，是近似值。第二、第三渠道各占多少公开页没给，公开页没列出具体引荐网站。
佐证：官网博客 22 篇，7 篇围绕 NotebookLM；官网写可接 Make、Zapier，提供 MCP；官网首页声明与 Google 无关联；官网主要是落地页，使用在 app 子域名里。
推论：把两个渠道圆拆给四路：直接输网址 0.7232 = 订阅用户回访 0.12 + 搜到后记住网址 0.2532 + Reddit 和创始人帖子 0.25 + 集成页 0.1；搜索、引荐等 1.0768 = 订阅用户回访 0.2 + 搜词 0.55 + Reddit 和创始人帖子 0.1 + 集成页 0.2268。回访约 0.32 万次，按 145 个订阅估的。搜到 10% 进站、社交内容 5%、集成页 5%，这几个比例和拆法都是猜的。每 100 次访问约 0.79 笔付款，是最后有收入那个月的付款笔数（含续费）除以上个月的总访问，是近似值。

## 一、产品
- 产品：AutoContent API 把 PDF、网址、YouTube 视频和文字转成 NotebookLM 风格的播客、讲解视频、信息图、幻灯片、测验和深度研究报告，提供 API、网页面板和 MCP，可接 Make、Zapier；官网声明与 Google 无关联。
- 用户群体：想批量自动生成播客和视频内容的内容创作者、自动化开发者和营销团队，包括用 Make/Zapier 搭工作流的人
- 定位：NotebookLM 没有官方 API 时的替代品：把 NotebookLM 式的音频概览做成可编程的 API，并扩展到视频、幻灯片、测验和自定义品牌，按积分计费。
