## 上个月流量模型
主引擎是SEO（搜索占位）：TrustMRR 的来源统计里 Google 约占 79%，搜索词除了品牌词，还有 apify 和 get all social media scraing under 1 api 这类非品牌词。
没有查到明确的涡轮加速：Show HN 只有 5 分；MCP 包和 Agent 技能包让 Claude、Cursor 之类的 Agent 直接调用，润滑剂是开发者反复买积分包。
按推算，约三成访问是买过积分的老用户回访；每 100 次访问约 0.4 笔付款（含重复购买）；访问量是估算的（按全球排名）。
模型：Lenny 的赛车增长框架。引擎 = SEO（搜索占位，Google 和 AI 助手搜索进来的开发者）；涡轮加速 = 没查到明确的一次性爆发；润滑剂 = 预付积分包、永不过期，用完要回来再买。
真实数据：直接访问占 38.07%、渠道排名（直接、自然搜索、自然社交）、搜索里自然搜索占 88.16%、国家（美国 15.13%、印度 9.28%、韩国 8.38%）、跳出率 38.02%、每次 2.5 页、停留 45 秒来自 Similarweb 公开页；9.52 万次总访问不是真数，是按 Similarweb 全球排名 #351468 估算的（用 215 个有真实访问的站拟合，一半的站误差在 15% 以内）；384 笔付款（Stripe）、收入 23,374 美元、1 个订阅来自 TrustMRR。
佐证：档案里 TrustMRR 自带的来源统计写 Google 约 79%、微软域名 6.9%、ChatGPT 4.7%；Similarweb 搜索词有 apify 和 get all social media scraing under 1 api；Show HN 帖 5 分、4 条评论；创始人自述首个客户来自 Threads 上的一条回复；引荐站 peerpush.com 0.67%、github.com 0.27%、apis.io 0.2%。
推论：把两个渠道圆拆给四路：直接输网址 3.62 = 老用户回访 2.0 + MCP 包 0.8 + 刷到帖子 0.42 + 搜索 0.4；搜 socialcrawl、apify 等词，点社交链接等 5.9 = 搜索 3.5 + 老用户回访 1.0 + 刷到帖子 0.86 + MCP 包 0.54。自然社交约 9% 是档案参考，不是 Similarweb 公开页的真数。搜索 5%、MCP 10%、帖子 5% 进站，这几个比例和拆法都是猜的；访问量是估算的，误差可能较大，每 100 次访问约 0.4 笔付款只是个量级。

## 一、产品
- 产品：开发者和 AI Agent 用一个 Key、一种统一返回格式，就能调用 Reddit、X、TikTok、Instagram、Threads 等几十个社交平台的数据，按调用扣积分，官方还提供 MCP 和 Agent 技能包。
- 用户群体：要做社媒监控、受众增长、舆情分析的开发者，以及需要实时社交上下文的 AI Agent 开发团队和营销数据公司
- 定位：对标 Firecrawl 的“社媒版”：统一接口和统一数据结构，不用分别对接各平台 API；预付积分包不订阅，积分永不过期

- 英文简介：Pay-per-call social media scraper API covering 69 platforms through one auth token and one response schema
