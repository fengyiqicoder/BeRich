## 上个月流量模型
主引擎是口碑传播：“Ahrefs 的开源替代品”在 GitHub 攒到 2.48 万星，营销 newsletter、YouTube 教程、TikTok 博主自发转述，直接打开占 43%，搜索热词大多是品牌名。
涡轮加速是 Product Hunt：首发拿到当日第一、当月第三，之后三个月星数涨了 2 万多；最近又发了一次拿到当日第 2，还进了 YC。
按推算，三成多访问是老用户回来查关键词和排名；每 100 次访问约 11 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 口碑传播（开源仓库的星数当社交证明 → 开发者圈、营销 newsletter、YouTube、TikTok 博主自发转述“免费替代 Ahrefs” → 直接打开和搜品牌名进站）；涡轮加速 = 两次 Product Hunt 发布和进 YC。
真实数据：43.32 万次访问（433200）、环比 +64.02%、第一大渠道直接占 42.64%、前三渠道排名（直接、自然搜索、引荐）、搜索里自然搜索占 99.99%、搜索词 281 个、热门搜索词（openseo、open seo、openseo github、backlink checker、open seo github）、引荐前几名（stripe.com 1.19%、saashub.com 0.55%、ycombinator.com 0.41%）、引荐类目开发者软件占 92.18%、社交来源（X、YouTube、Facebook）、外链去向 github.com、国家（美国 22.91%、印度 17.04%、印尼 6.3%、越南 5.93%、德国 4.01%）、跳出率 39.08%、每次 4.66 页、平均停留 2 分 17 秒、全球排名 91293，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。47278 次（4.73 万）去 Stripe 付费页来自 quietmoney 收款页数据，上两个月 23146 次，再往前一个月为 0，更早几个月月均约 3,100 次。

推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 18.47 = 老用户 10 + 刷到视频、newsletter 后直接打开 4.47 + GitHub 和 Product Hunt 来的 4；其余渠道 24.85 = 刷到视频、newsletter 后搜品牌名 8 + GitHub 引荐和搜 openseo github 7 + 老用户搜品牌名 5.5 + 搜 backlink checker 等工具词 4.35（按档案里品牌词约占搜索的四分之三估）。在 GitHub 等处看到 5% 进站、刷到视频 3% 进站、搜到工具词 10% 点进来，这几个比例是猜的。自托管用户嫌部署和计费麻烦后转托管版，是档案的推测。
