## 上个月流量模型
主引擎是新模型上架截流：热门模型一出就上架，再用多语种博客接“某模型 API”的搜索；直接打开占 61%，多是回来调模型的老用户。
起家靠开源：stable-fast、Comfy-WaveSpeed 等仓库在 ComfyUI 圈攒下几千星，主页都指向 wavespeed.ai；联盟分佣 10% 是润滑剂，引荐第一是联盟平台 impact.com。
按推算，约一半访问是老用户回来生成图片、视频；每 100 次访问约 10 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 新模型上架截流（热门模型一出就上架，多语种博客和付费搜索接“某模型 API”的搜索）；涡轮加速 = 起家时把开源仓库攒下的 ComfyUI 开发者导过来；润滑剂 = 10% 联盟分佣，加上按次计费让老用户反复回来充值。
真实数据：180 万次访问、环比 -5.78%、第一大渠道直接占 61.24%、前三渠道排名（直接、自然搜索、引荐）、搜索里自然搜索占 71.8%、付费搜索 28.2%、搜索词 12.1K 个、热门搜索词（wavespeed ai、wavespeed、wavespeedai、video watermark remover、seedance 2.0）、引荐前几名（impact.com 8.95%、feishu.cn 3.25%、socialmediagirls.com 1.89%）、社交来源（YouTube、Facebook、X）、国家（美国 20.01%、印度 8.69%、英国 4.27%、巴西 3.98%、西班牙 3.38%）、跳出率 34.85%、每次 5.51 页、平均停留 8 分 11 秒，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。189112 次（18.91 万）去 Stripe 付费页来自 quietmoney 收款页数据。
佐证：创始人成泽毅 2023 年起开源 stable-fast、ParaAttention、Comfy-WaveSpeed，仓库主页后来都指向 wavespeed.ai；域名 2025 年注册，同年宣布数百万美元天使轮；每上一个新模型就在 HN 发帖（多数只有 1～2 分），博客按模型批量出文章并翻成多种语言；联盟计划 10% 返佣、每个客户封顶 $150；官网自称 1M+ 用户、1000+ 模型。
推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 110.23 = 老用户 80 + GitHub 和 ComfyUI 12 + 搜新模型后再打开 10 + 联盟博主 8.23；其余渠道 69.77 = 搜新模型 API 35 + 联盟博主和 YouTube 16.77 + 老用户搜品牌名 10 + GitHub 8。Semrush 电脑端数据显示直接 78.8%、搜索 21.2%，说明第二个圆里搜索是大头，所以新模型搜索分得最多。搜到新模型 8% 点进、在 GitHub 看到 10% 点进、看联盟博主推荐 3% 点进，这几个比例是猜的。
