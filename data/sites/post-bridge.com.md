## 一、产品
- 产品：社媒排期 SaaS：在一个后台写内容，同时发布到 TikTok、Instagram、YouTube Shorts、X、LinkedIn、Facebook、Threads、Bluesky 等平台，也提供 API 供 AI 智能体调用发帖。
- 用户群体：一个人负责给自己的产品或账号做社媒运营的独立开发者、创作者和小团队
- 定位：同类排期工具月费常要 $150–$300，Post Bridge 做得更便宜更简单（$39 起），并靠 API 接入 AI 智能体

- 团队：一个人

- 英文简介：Social media scheduling SaaS: write once and publish to multiple platforms from one dashboard
