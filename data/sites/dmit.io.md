## 上个月流量模型
主引擎是圈内口碑和返佣：直接打开占 73%，搜索词全是 dmit、dmit vps、dmit官网 这些品牌词；返佣链接遍布中文测评博客和 GitHub 导购页。
润滑剂是限量补货和续费：便宜的限量款只在补货时放出，NodeSeek 上有人盯补货、溢价转卖；买了 VPS 的老用户也要常回来管机器、续费。
按推算，约一半访问是老用户回来管机器、续费；每 100 次访问约 7 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 圈内口碑和返佣（中文 VPS 圈 hostloc、NodeSeek、linux.do 的口碑，加上 WHMCS 推广返佣养出的测评博客和 GitHub 导购页）；润滑剂 = 限量款补货制造话题，以及买了 VPS 的老用户回来管机器、续费。

推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 29.744 = 老用户 20 + 在 linux.do、NodeSeek 看到 6 + 测评博客、GitHub 导购页 2.744 + 刷到 X、YouTube、Telegram 1；其余渠道 10.796 = 在 linux.do、NodeSeek 看到 4 + 测评博客、GitHub 导购页 3.5 + 刷到 X、YouTube、Telegram 1.796 + 老用户搜品牌名或从 Stripe 付完款跳回 1.5。引荐里 stripe.com 占 4.51%，多半是付完款跳回来的老用户。在社区看到 10% 点进来、看到返佣导购页 5% 点进来、刷到社交帖子 2% 点进来，这几个比例是猜的。搜索里 15.98% 是付费搜索，谁在买品牌词档案里没查到。
