## 上个月流量模型
主引擎是作者自己的 B 站首发：做 AE 动效内容的 UP 主 _OXOX_ 发了首发视频，2.5 万播放、1968 收藏，远超他 7 千粉；Similarweb 公开页没有这个站的渠道数据。
润滑剂是积分制：新用户送 1200 额度，用完要回网站买 $2.90 起的积分包或 $9.90/月起的订阅，客户端和 AE 插件也要回网站登录、建 API Key。
按推算，大部分访问是装了客户端的用户回来登录、买额度；访问量是估算的，每 100 次访问约 15 次点进 Creem 付费页，这正是估算总访问时假设的比例。
模型：Lenny 的赛车增长框架。引擎 = 作者自己的 B 站首发（做 AE 动效内容的 UP 主发首发视频，在 AE 创作者圈里被收藏、转发）；润滑剂 = 积分制和桌面客户端（送 1200 免费额度，用完回网站买积分包或订阅，客户端要登录建 API Key）。
真实数据：Similarweb 公开页没有这个站的全球排名和渠道数据，国家、设备、跳出率也都没有；5312 次（0.53 万）去 Creem 付费页来自 quietmoney 收款页数据。
佐证：作者 _OXOX_ 在 B 站约 7 千粉，B 站简介说这是近半年持续开发的个人项目；首发视频 25463 播放、1816 赞、1968 收藏、287 分享、140 评论（B 站 API）；域名 2026 年注册；定价是积分包 $2.90（1500）、$12（7500），订阅 Starter $9.90/月、Pro $19.90/月、Max $39.90/月；社区画廊里有用户发布的作品和评论；作者之后又在 GitHub 发了依赖 ArbiFX 插件的 Code2AE skill，18 star，不算在上个月的访问里。
推论：3.51 万次总访问没有全球排名可用，是按付费页访问 0.53 万 ÷ 小站常见比例 15% 估算的，可能差好几倍，所以渠道圆带 ≈；也因此“进站 → 付费页”的 15% 是假设，不是测出来的。渠道没有数据，只画一个圆。各路怎么拆是推论：3.51 = 客户端用户回来登录、买额度 3.0 + 刷到 B 站首发视频 0.36 + 看到别人分享的特效作品 0.15；首发视频总共只有 2.5 万播放，所以这一路给得少。档案里记过引荐 95.5%，是之前的口径，只拿来判断大头可能是客户端登录跳转和视频简介链接。看完视频 15% 进站、看到作品 10% 进站，这两个比例是猜的。
