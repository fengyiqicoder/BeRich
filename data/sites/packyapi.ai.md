## 上个月流量模型
主引擎是买开源工具的推荐位、联盟返利：赞助 14.8 万星的 cc-switch，把自己做成软件里的预设供应商，再用带 aff 的返利链接请人写推广；直接打开占 68%，引荐和联盟排第二、第三。
涡轮加速是 Claude Code 在国内开发者圈爆火：2025 年起国内直连和付费都难，它作为 Claude Code 中转上线，正好接住这波需求。
按推算，近一半访问是老用户回来充值、看用量；每 100 次访问约 13 次点进 Stripe 付费页。
模型：Lenny 的赛车增长框架。引擎 = 花钱买分发（赞助开源工具 cc-switch 的预设和 README 赞助位、开源赞助计划、aff 联盟返利）；涡轮加速 = Claude Code 在国内开发者圈爆火；润滑剂 = 按量计费，老用户要反复回来充值。
真实数据：16.09 万次访问、环比 -39.56%、第一大渠道直接占 68.45%、前三渠道排名（直接、引荐、联盟）、搜索里自然搜索占 100%、搜索词只有 5 个（packyapi、deepseek、packyapi.ai、workbuddy 接入 grok）、引荐前几名（gitcode.com 5.52%、hvoyai.com 1.63%、oken.ai 1.51%）、社交来源（DeviantArt、X、YouTube）、国家（中国 58.73%、美国 13.6%、新加坡 8.39%、台湾 7.44%、香港 6.15%）、跳出率 29.91%、每次 7.4 页、平均停留 7 分 17 秒，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。21490 次（2.15 万）去 Stripe 付费页来自 quietmoney 收款页数据。
佐证：cc-switch 的 git 历史里，2025 年先把 packycode 列为预设供应商，同年再加为官方赞助（README 中英文赞助位、软件内推广语、aff=cc-switch 返利链接、首充 9 折码），现在 14.8 万星，赞助位仍是它；GitHub Gist 上有注册链接全带 aff 的推广长文；官网 /partners 有开发者生态合作计划；服务状态挂在 Linux.do 监控站，问题进 QQ 群。
推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 11.01 = 老用户 7.5 + cc-switch 软件里点链接 2.5 + 推广文章 0.51 + 社区推荐 0.5；其余渠道 5.08 = 推广文章的联盟链接 2.2 + cc-switch 的 README 和 gitcode 镜像 1.8 + 社区推荐 0.78 + 老用户搜品牌名 0.3。从桌面软件里点链接通常算作直接打开，所以把一部分 cc-switch 流量放在直接里。看到 cc-switch 赞助位 5% 点进来、看到推广文章 3% 点进来、听到社区推荐 10% 点进来，这几个比例是猜的。档案提醒付费页 2.15 万次和 venice.ai 等站完全一样，可能是数据源分档估的，照用。
