## 上个月流量模型
主引擎是口碑传播：直接打开占 64%，搜索全是自然流量、热门词全是品牌词，新客是在教程、厂商文档和 GitHub 上看到后来搜名字下载的。
DeepSeek 爆火是一次涡轮加速：2025 年初大量“Ollama + DeepSeek + Chatbox”本地部署教程把它写成默认前端。
按推算，约一半访问是老用户回来聊天；每 100 次访问约 3 次点进付费页。
模型：Lenny 的赛车增长框架。引擎 = 口碑传播（开源仓库、第三方教程、模型厂商接入文档把它当推荐客户端，读者来搜品牌名、下载）；涡轮加速 = 2025 年初 DeepSeek 爆火带起的本地部署教程；润滑剂 = 天天要用的聊天客户端，老用户反复打开。
真实数据：67.57 万次访问、环比 -21.48%、第一大渠道直接占 63.66%、前三渠道排名（直接、自然搜索、引荐）、搜索里自然搜索占 100%、搜索词 591 个、热门搜索词（chatbox、chatbox ai、chat box、chatbox app、chatbox download）、引荐前几名（volcengine.com 5.77%、qianwen.com 4.59%、github.com 4.21%）、社交来源（YouTube、X、Reddit）、外链去向（deepseek.com、chathub.gg、z.ai）、国家（中国 47.22%、香港 6.21%、美国 6.07%、印度 4.66%、土耳其 3.85%）、跳出率 37.67%、每次 3.95 页、平均停留 1 分 59 秒，来自 Similarweb 公开页上个月；第二、第三渠道各占多少公开页没给。21490 次（2.15 万）去 Stripe 付费页（checkout.stripe.com；pay.stripe.com 为 0）来自 quietmoney 收款页数据，之前几个月月均约 2.45 万次。
佐证：2023 年作者把自己调 prompt 用的桌面客户端开源到 GitHub，现有 4.2 万星；中文效率工具论坛 Quicker 上网友自发转发；r/ChatGPT 有“Chatbox Changed My Life”帖，用户说是在 GitHub 上发现的；2025 年 HN 帖 110 分；2025 年初阿里云、腾讯云等出现大量“Ollama + DeepSeek + Chatbox”部署教程；2025 年美区 App Store 因商标投诉下架，后被法院令恢复。
推论：两个渠道圆是真的，各路怎么拆是推论：直接输网址 43.02 = 老用户 30 + 社区推荐 7.02 + 教程和厂商文档 6；其余渠道 24.55 = 教程和厂商文档（搜品牌名、点文档里的链接）12.55 + GitHub、Reddit、论坛推荐 8 + 老用户搜名字下载更新 4。Semrush 电脑端数据显示直接 72.2%、搜索 26%、AI 1.8%，所以第二个圆里多算给了搜品牌名的人。看教程和文档 10% 进站、看到社区推荐 5% 进站，这两个比例是猜的。
